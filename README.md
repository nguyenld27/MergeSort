# Thí nghiệm CUTOFF 7 và 10

Cần Java 11 trở lên. Mở terminal tại thư mục này và chạy:

```text
javac MergeSort.java Benchmark.java
java Benchmark
```

- `MergeSort.java` cài đặt Mergesort và dùng Insertion sort cho các đoạn ngắn.
- `Benchmark.java` đọc dữ liệu, chạy thử và in bảng thời gian.
- `data.txt` chứa 10.000 số nguyên, mỗi dòng một số. Mở bằng Notepad.
- [REPORT.md](REPORT.md) ghi kết quả và cách đo.
